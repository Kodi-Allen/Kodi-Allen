I maintain community add-ons and skin customizations for **Kodi**, with a focus on media libraries, playback and a useful living-room interface.

**New here? Start with the [Kodi Allen Repository](https://github.com/Kodi-Allen/kodi-repo#installation)** to find the add-ons and installation instructions.

## Projects

- **[Kodi Allen Repository](https://github.com/Kodi-Allen/kodi-repo)** — The installation hub for all add-ons, artwork tools and Aeon Tajo. [Install & browse add-ons](https://github.com/Kodi-Allen/kodi-repo#installation).

- **[TubiTV](https://github.com/Kodi-Allen/kodi-repo/tree/main/plugin.video.tubitv)** — Unofficial Tubi add-on with its own interface, library export and optional account features. [Features & screenshots](https://github.com/Kodi-Allen/kodi-repo/blob/main/plugin.video.tubitv/README.md).

- **[ParkStream](https://github.com/Kodi-Allen/plugin.video.parkstream)** — Unofficial South Park add-on for Kodi 21 (Omega), using the official regional websites. [Guide & screenshots](https://github.com/Kodi-Allen/kodi-repo/blob/main/docs/parkstream/README.md).

- **[Aeon Tajo — Tweaked](https://github.com/Kodi-Allen/skin.aeon.tajo-tweaked)** — Customizations of manfeed's Aeon Tajo skin. [Skin guide, branches & installation](https://github.com/Kodi-Allen/skin.aeon.tajo-tweaked#readme).

## Contributions to Kodi

Two fixes contributed to the main Kodi project have been merged:

- [Blu-ray playlist playback from dynamic paths](https://github.com/xbmc/xbmc/pull/28288)
- [NFS: reject directory opens as files](https://github.com/xbmc/xbmc/pull/28286)

My forks of [Kodi](https://github.com/Kodi-Allen/xbmc) and the [original South Park add-on](https://github.com/Kodi-Allen/plugin.video.southpark_unofficial) are used for upstream contributions. **For ParkStream installation and support, use the projects above.**

## Installation & support

- Follow each project's guide for its Kodi requirements, installation packages and known limitations.
- Report a problem in the relevant repository's **Issues**, including your Kodi version, add-on version and steps to reproduce it.
- Remove passwords, access tokens and private paths before sharing logs.
